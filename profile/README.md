# Aequalyn

An Arch-based Linux desktop for Hyprland, built around its own Quickshell
shell. Colours follow your wallpaper or a theme you pin, and everything the
picker does is also a command you can script.

| Repository | |
| --- | --- |
| [aequalyn](https://github.com/Aequalyn/aequalyn) | Core: `aequalyn-*` commands, default configuration, `install.sh` |
| [aequalyn-shell](https://github.com/Aequalyn/aequalyn-shell) | The desktop shell: shaped bar, up to 16 docks, launcher, notifications, Atelier, settings |
| [aequalyn-themes](https://github.com/Aequalyn/aequalyn-themes) | Themes: a palette with matching backgrounds |
| [aequalyn-installer](https://github.com/Aequalyn/aequalyn-installer) | Guided installer with a reviewable `install.toml` |
| [aequalyn-iso](https://github.com/Aequalyn/aequalyn-iso) | Live / install ISO builder |
| [aequalyn-pkgs](https://github.com/Aequalyn/aequalyn-pkgs) | Package lists, install profiles and PKGBUILDs |

[aequalyn.com](https://aequalyn.com)
